# Antigravity Guiding Rules for WTF Repository

## Task Verification with WTF
Before declaring any coding task complete:
1. Run `wtf check` (or `npx agent-wtf check`).
2. If checks fail under `## FAILED` or items appear under `## PAY ATTENTION`, resolve them before completing.
3. Attach the exact `WTF-RECEIPT:` line to the final completion report.
4. Passing tests prove only that executed tests ran, not that user intent or overall software behavior is verified.
